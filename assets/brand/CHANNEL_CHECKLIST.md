# First-publish checklist (channels)

Use after brand assets are on `main`. English default; Chinese for 小红书 / 抖音.

## 0. GitHub (before social)

- [ ] Social preview uploaded: repo **Settings → General → Social preview** → `assets/brand/og-github.png`
- [ ] Description / topics match [COPY_BANK.md](COPY_BANK.md)
- [ ] README EN + [README.zh-Hans.md](../../README.zh-Hans.md) reflect capability pillars

## 1. X (Twitter)

**Avatar:** `logo.png` or app icon  
**Bio:** from COPY_BANK → X → Bio  

**Pin post (EN):**

```
Line — native macOS window manager.

First-class grid · multi-display · high performance · open source.

Snap to the line.
github.com/nnecec/Line
```

**Media:** `cover-x.png` or a redacted grid demo.

## 2. 小红书

**Avatar:** same as X  
**简介:** COPY_BANK → 小红书 → 简介  

**首发标题建议:**

```
Mac 原生窗口管理：网格优先 | Line
```

**正文骨架:** COPY_BANK → 发版正文骨架（首发把「本次更新」换成产品介绍）  
**封面:** `cover-xhs.png`

## 3. 抖音

**Avatar / 主页简介:** 网格优先 · 多屏幕 · 高性能 · 开源 · 一线到位  
**首发:** 15–30s 网格 + 多屏 before/after；片尾 `cover-douyin.png` 或同文案  
**口播:** COPY_BANK → 抖音

## 4. Do not

- Lead with “需要辅助功能” / “Accessibility required”
- Lead with keyboard/mouse as the product story
- Use a logo that is not `logo.png`
- Ship personal window titles in demos

## 5. Install footnote (optional, end of post)

Only if users ask how to install: Releases → right-click Open → Accessibility. Keep it out of the hero line.
