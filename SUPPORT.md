# Support

Line is an open source **native macOS** window manager (personal fork of Loop). Support is provided through GitHub issues when contributor time is available.

Use the bug report form for reproducible Line behavior. Include the Line version, macOS version, hardware, Accessibility permission state (needed for diagnosis), and minimal reproduction steps. Redact window titles, file paths, and personal information from screenshots and logs.

Use the feature request form for product changes—especially around **grid**, **multi-display**, and performance. Questions about the original Loop project should go to [MrKai77/Loop](https://github.com/MrKai77/Loop).

Security vulnerabilities must follow [SECURITY.md](SECURITY.md). Public issues containing credentials or sensitive user data may be removed.
