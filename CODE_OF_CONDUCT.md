# Code of conduct

Line welcomes contributors with different backgrounds and levels of experience. Project discussions should stay focused on the work and treat participants with respect.

Acceptable participation includes giving specific technical feedback, asking for evidence, acknowledging mistakes, and allowing maintainers time to review volunteer work.

Harassment, personal attacks, discriminatory language, threats, publishing private information, and sustained disruption are not accepted. Maintainers may edit or remove content, close discussions, reject contributions, or restrict participation when needed to protect the project and its contributors.

This policy applies to repository issues, pull requests, discussions, release channels, and project-related private communication. To report conduct privately, use [GitHub private vulnerability reporting](https://github.com/nnecec/Line/security/advisories/new) and start the report title with `Conduct report`.
